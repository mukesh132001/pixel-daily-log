# Room art credits

The room and furniture sprites in this folder come from the **ToffeeCraft** cozy isometric room pack (paid version). The creator gave permission to use them on this public site.

- Only the sprites the game draws are copied here, cut out of the pack's sheets pixel for pixel (no resizing).
- Please don't reuse or redistribute them outside this project. Get the pack from ToffeeCraft instead.
- The raw pack lives in `assets/`, which is ignored by git on purpose.
