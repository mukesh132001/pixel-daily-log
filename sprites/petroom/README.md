# Pet room art (original, owned by Pixmod)

The dog room from `tools/dogroom/`, exported in the same format as `sprites/room/` (read that README for the
scale, draw order, depth sorting, blocked tiles and interactions: they all work the same here).

Generated by `tools/dogroom/export_room.py` (needs Pillow). Don't edit these PNGs by hand: change the scripts and run
`python export_room.py` again.

## Files
- `room_shell.png`: floor + walls, 256x256, always drawn first
- one PNG per item, cropped to its pixels (position in the manifest)
- `petroom_manifest.json`: where each item goes and how it behaves, plus `petSpots`
- `preview_full.png`: the room with four sample pets and Leo
- `preview_spots.png`: blocked tiles (red), the pet door tile (yellow), where Leo arrives (green) and the pet spots

Put the pieces back together in draw order and you get the original render pixel for pixel (the export script checks this).

## depthY
Computed by the export script, not guessed: for each piece, the value where Leo is drawn the right way round at the most
floor spots, then adjusted so pieces that overlap each other keep their true order (the plant stays in front of the dog bed).

## Pets
`pet` in the manifest describes the pet frames (28x30, feet at column 14, row 28). `petSpots` says where pets can be:
- `x, y`: where their feet go (world units); `z`: how far up (on a cushion)
- `pose`: `sit`, `eat` or `sleep`; `kind`: `dog`, `cat` or `any`
- `on`: the item they sit on or in front of; draw the pet right after it (its depthY + 0.1)

| Spot | Kind | Pose |
|---|---|---|
| rug_mid, rug_left, rug_right | any | sit |
| bowl | any | eat |
| dog_bed | dog | sleep |
| kennel (in the doorway) | dog | sleep |
| cat_bed | cat | sleep |

## Doors
`spawnTile` is where Leo arrives: one tile in front of the pet door. The pet door (tile 8, 1) leads back to the room.
